BOOKSWAP - CATÁLOGO DE DEMOSTRACIÓN

1. Extraiga todo el ZIP en una carpeta.
2. Abra esa carpeta en VS Code.
3. En la terminal de esa carpeta ejecute: python main.py
4. Use la opción 2 para mostrar los libros y la opción 3 para buscar.

Todos los registros son ficticios: títulos de demostración, autores,
propietarios, precios y asociaciones con universidades. No son inventarios
oficiales ni una verificación de las carreras ofrecidas por cada universidad.

Los códigos identifican publicaciones y no se pueden repetir.
Para publicar otro libro, use un código libre (por ejemplo, 1201).
La opción 1 publica un libro NUEVO; los ejemplos ya están registrados.
La opción 4 solicita un libro cuya modalidad sea Préstamo.

libros_ejemplo.txt solo se lee cuando no existe libros.txt.
Al guardar, se crean libros.txt y solicitudes.txt con los datos actuales.
Si ya tiene datos de la versión anterior, se conservan y no se mezclan
con los ejemplos. Para probar este catálogo, use una carpeta nueva.
No borre sus archivos de datos anteriores.

MÓDULOS
main.py: menú.
catalogo.py: lista enlazada de libros, publicación y búsqueda.
prestamos.py: cola FIFO y devoluciones.
archivos.py: lectura y guardado en texto.
entradas.py: lectura y validación de cadenas y números.
